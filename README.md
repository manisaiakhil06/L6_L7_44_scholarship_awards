# L6-L7 Scholarship Awards Labs

This repository contains completed working materials for Lab 6 (code/branch coverage) and Lab 7 (Hypothesis fuzz testing).

- `Lab 6/`: completed regression tests, separate code-coverage and branch-coverage test files, and commands in the folder README.
- `Lab 7/`: defensive input handling and Hypothesis property-based tests, with run instructions in the folder README.

See each lab's README for commands. Lab 6 was locally verified at 100% statement coverage and 100% branch coverage. Lab 7's application was checked against 20,000 randomized inputs in this environment; the Hypothesis test suite still needs to be run in an environment where `hypothesis` can be installed.
